# LabScope

轻量实验数据监测网页。Node.js 18+，无需安装第三方依赖。

运行：在本目录执行 `npm start`，打开 http://localhost:8080 。同一局域网手机访问 http://电脑IP:8080（需允许防火墙入站）。关闭终端停止服务。服务端会**常驻采集**：进程活着就每 5 秒查询一次并落盘，与浏览器是否打开无关。

也可直接双击 `start.bat`：自动启动服务并打开浏览器；若 8080 被其他程序占用，会在 8080–8090 之间自动挑一个空闲端口，实际地址以窗口中打印的为准。`start.bat` 以 GBK 编码保存（Windows 批处理需要 CRLF 与本地代码页），编辑时请保持编码，否则中文提示会乱码。若 PowerShell 提示 `npm.ps1 cannot be loaded because running scripts is disabled`（本机执行策略限制），改用 `npm.cmd start` 或 `node server.js`。

也可以直接双击 `public/index.html` 用浏览器打开（直接打开模式）：数据由浏览器直连 OneNET 查询（该接口已返回 CORS 头，实测 `Access-Control-Allow-Origin: *`，无需代理）。该模式下配置与连接信息存放在浏览器的 `file://` 源中，与通过 http://localhost:8080 访问时**不共享**。

局域网放行入站端口（管理员 PowerShell 执行一次，`-LocalPort` 按 `start.bat` 实际打印的端口调整）：`New-NetFirewallRule -DisplayName "LabScope" -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow`

## 服务端常驻采集（本地/自建部署）

页面每次打开可能只有几分钟，靠页面自己攒数据必然缺段。因此 `server.js` 启动后会自己按间隔查询 OneNET，并把数据追加到 `data/history.jsonl`；页面打开时自动读取服务端历史，**离开页面期间的曲线缺口会被真实数据补齐**（无服务端时才退化为虚线标注的「未采样」）。

- 凭据来源（按优先级）：① `labscope.config.json`（本地文件，最省事，可完全无人值守）；② 环境变量 `PRODUCT_ID` / `DEVICE_NAME` / `TOKEN`；③ 在页面工具行点「后台未采集 · 点此开启」（**显式操作**，凭据仅存服务端内存，服务重启后失效）。
- 重要：**后台采集默认不开启**。打开页面时是"页面在采"——每秒一次，仅在本页面可见时工作；切到后台或关掉页面就停，那段曲线会以虚线标注为「未采样」。只有上面 ①/②/③ 任一生效后，后台才会独立采集，**关掉页面也不中断**（要停止：点工具行的绿色胶囊确认停止，或直接关闭 `start.bat` 窗口）。
- 参数：`POLL_MS`（默认 5000，最小 1000）、`RETENTION_DAYS`（默认 7 天）、`PORT`（默认 8080）。
- 数据：`data/history.jsonl`，每行一条 `{identifier,time,value}`，内存最多保留 20 万条，文件超过 20MB 自动压缩（丢弃保留期外的记录）。启动时会打印「已载入历史 N 条」，这是把已落盘的历史读回内存，不是报错。
- 单实例保护：`data/collector.lock` 记录采集进程的 PID 与端口。重复双击 `start.bat` 时，第二个实例（会占到另一个端口）**只提供页面与查询转发、不重复采集**，启动日志会写明；否则两个进程会同时写同一份历史，导致 OneNET 配额翻倍并出现重复时间戳。首次启动会看到「已载入历史 N 条」这类信息。
- 历史去重：载入时同一标识符同一时间戳只保留一条；若发现重复（早期多实例同写留下的），会提示一次并重写文件去重。
- 接口：`GET /api/status`（采集状态、设备在线状态、条数）、`GET /api/history?minutes=N`（历史记录）、`GET /api/history.csv?minutes=N`（导出服务端历史为 CSV，列与服务端存储一致：`source,identifier,platform_time,received_time,value`；页面工具行有「时间范围 + 导出服务端历史」按钮，无服务端时自动隐藏）、`POST /api/credentials`（页面把凭据交给服务端开始采集）、`DELETE /api/credentials`（停止采集），以及原有的 `/api/properties`、`/api/device` 单次查询转发。
- 安全：服务端仍只做只读查询，不记录日志。若把 Token 写进 `labscope.config.json`，它会**以明文保存在本机磁盘**；该文件已加入 `.gitignore`，切勿提交或共享。
- 与 GitHub Pages 的关系：Pages 是纯静态托管，**没有服务端进程**，常驻采集不生效——发布到 Pages 的站点打开时是浏览器直连，关闭页面期间不会采样（缺口以虚线标注）。需要线上也连续，可改为把服务端部署到一台常开的机器（VPS/家里的电脑 + 隧道），或后续接入 OneNET 历史数据接口在打开页面时补采。

## 发布到 GitHub Pages（静态部署，无需服务端）

访问者的浏览器直接调用 OneNET 接口（该接口返回 CORS 头，实测可跨域），所以纯静态托管即可查询真实设备。前端会自动探测：页面能访问到本机 `/api/properties` 时走服务端代理，否则（GitHub Pages、直接双击打开）切换为浏览器直连，两种模式共用同一份 `public/`。

本工具随 `self-developed-tools` 仓库发布，该仓库的 Pages 发布源是 **`main / root`**（分支部署，非 Actions 工作流），所以不需要额外的工作流文件：推送到 `main` 后，静态页面即出现在

```text
https://chengzhiyaoguoli.github.io/self-developed-tools/research-lab/LabScope/public/
```

（`index.html` 使用相对路径引用 `style.css` / `app.js`，可放在任意子路径下。`server.js`、`start.bat` 只在本地/局域网使用，不影响静态页面。）

- 安全：本仓库不含任何 Token；Token 由访问者在页面中填写，默认只存在页面内存，勾选「记住连接信息」后才写入该浏览器的本地存储。公开仓库请勿提交 Token。
- 配额：静态模式下每位访问者用自己填写的 Token 消耗 OneNET 查询配额；页面约 1 秒轮询一次，若让多人共用同一个 Token，需自行评估配额与限流。

可编辑、删除、添加卡片和曲线，使用箭头或拖动控件标题排序。曲线窗口默认 5 分钟，可在趋势图右上角「窗口」切换 1 分钟 / 5 分钟 / 15 分钟 / 30 分钟 / 1 小时（选择保存在本浏览器，卡片内嵌曲线同步）。可暂停滚动及设置纵轴（上下限即纵轴范围，趋势图右上角可直接改，迷你曲线同步）。**控件配置（含上下限、图标、颜色）与连接信息都保存在当前浏览器**：连接弹窗里勾选「记住连接信息」（默认勾选）后，下次打开页面会自动连接，取消勾选则凭据只留在内存、刷新即需重填，也可在弹窗里点「清除已保存」删除。导出的配置文件始终不含 Token。

OneNET使用原参考项目相同的属性查询接口：`https://iot-api.heclouds.com/thingmodel/query-device-property`，Authorization请求头。服务端只转发此只读查询，不保存凭据。参考项目：https://github.com/NaHSIT/IOT_Application 。本项目代码独立实现。

顶部状态胶囊依次可能显示：**未配置 OneNET**（尚未填写凭据，点击可直接打开连接设置）、**连接中…**、**设备在线** / **设备离线**、**查询成功**（平台未返回设备状态字段时）、**查询失败**、**演示数据**、**后台暂停**。设备在线状态取自 `https://iot-api.heclouds.com/device/detail`（`data.status` 为 1 表示在线、0 表示离线），约每 10 秒查询一次；有服务端时经 `/api/device` 转发，静态部署时由浏览器直连。设备离线不代表页面停止查询，卡片仍会按平台时间提示「数据陈旧」。

每次查询完成后约1秒再次查询；页面后台暂停。查询成功不等于设备在线，卡片按平台时间提示数据陈旧。无平台时间戳的数据只显示、不记录；相同及倒序时间戳不重复记录。曲线超过2.5秒间隔断开（页面切到后台这段时间本就没有采样，用虚线连接而不是断开）。`导出本次记录`为当前会话获取的属性记录（长表格式），不保证获取设备每一个上报包；`导出服务端历史`导出的是服务端已落盘的历史（可选最近 30 分钟 ~ 7 天），两者列格式一致。最多保存100000条属性记录在内存，刷新页面丢失；及时导出。曲线窗口（默认 5 分钟，可调 1 分钟 ~ 1 小时）不影响记录保存。选择更长的窗口时，页面会向服务端请求对应的历史范围（有服务端时）。

演示模式使用明确标注的模拟数据，按标识符生成，与控件顺序无关；未知标识符会自动生成稳定的模拟曲线。

服务默认监听局域网，不包含公网用户鉴权；当前用于自己的电脑及可信局域网。公网部署应添加HTTPS和访问控制，局域网HTTP传输不加密。真实Token请使用具有API查询权限的凭据。直接打开模式与静态部署模式下不经过服务端，Token 由浏览器直接发给 OneNET：默认只存在页面内存，勾选「记住连接信息」后以**明文**保存在本浏览器本地存储中，公共电脑上请勿勾选。
